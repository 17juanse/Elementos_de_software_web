3. ¿Qué significa que un lenguaje sea turing completo? Significa que ese lenguaje tiene la capacidad de resolver cualquier problema computacional que pueda resolverse mediante un algoritmo, siempre que disponga de suficiente tiempo y memoria. En otras palabras, puede simular una Máquina de Turing, que es un modelo matemático capaz de ejecutar cualquier cálculo lógico. Ejemplos de lenguajes Turing completos son Python, Java o C.

4. ¿Por qué CSS y HTML no son lenguajes de programación?
Porque no cumplen con las características necesarias para serlo:

HTML se usa para estructurar contenido (definir títulos, párrafos, imágenes, etc.).
CSS se usa para dar estilo (colores, tamaños, diseños).

Ninguno de los dos puede:

Tomar decisiones (no tienen condicionales como if)
Repetir procesos (no tienen bucles como for o while)
Manipular datos de forma lógica

Por eso, no son Turing completos ni permiten crear algoritmos, que es lo esencial en un lenguaje de programación.
